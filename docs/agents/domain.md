# Domain-document conventions

Research-to-Repo is a single-context repository. Its shared vocabulary lives
in the root [`CONTEXT.md`](../../CONTEXT.md), and its architecture decisions
live in [`docs/adr/`](../adr/).

Create an ADR only when a decision is hard to reverse, surprising without
context, and selected through a real trade-off. Record ordinary reversible
implementation details with the work they support rather than adding ADRs.
